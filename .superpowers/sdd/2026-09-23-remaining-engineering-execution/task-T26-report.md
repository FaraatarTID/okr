# T26 Control-Plane Runtime Contract — Implementation Report

Date: 2026-09-23  
Status: implemented locally; contract-chain verification passed.

## Decision implemented

- Removed `POST /control-plane/environments/{environment_id}/lifecycle-events`; runtime has no ephemeral lifecycle write that can return success and disappear on restart.
- Kept operator-only GET list/detail backed by an explicitly empty route-local `ControlPlane(state_path="")`. This keeps the backend API independent of the operator file and environment variable, while operator CLI commands retain their explicit file-backed lifecycle records.
- Kept `/control-plane/v1/rollouts/{rollout_id}` as the separate SQL-backed operator route.
- Left the existing process-template/config rule prohibiting `OKR_CONTROL_PLANE_STATE_PATH` unchanged and added a real-app runtime test proving the route still ignores the file if that variable is injected.

## Test-first evidence

Added `tests/test_control_plane_stateless_api_contract.py` before changing route implementation. Initial subprocess run used the actual FastAPI app and a seeded operator file. The first attempt entered app lifespan and failed during unrelated SQLite/Alembic bootstrap (`no such table: user`), so the request probe was corrected to instantiate `TestClient` without lifespan startup. The corrected RED then failed on the intended assertion: the legacy API exposed `env-recorded-by-cli` from `OKR_CONTROL_PLANE_STATE_PATH`. After the route-local empty registry and POST removal, the same probe passed.

The runtime probe covers: seeded operator file ignored; list is empty; detail is 404; lifecycle POST is 404/405; SQL fleet route remains registered (503 only because no SQL service is configured); authenticated operator allowed and customer principal denied. Existing explicit `ControlPlane(state_path=...)` persistence/reload test remains in `tests/test_control_plane_stateless_runtime.py`.

## Runtime probe clarification

The RED probe was not a fake router or fake service. It imported the real backend app in an isolated subprocess and deliberately supplied `OKR_CONTROL_PLANE_STATE_PATH` to exercise the legacy implicit `ControlPlane()` environment-variable fallback. That setting is excluded from normal runtime templates, but the old route nevertheless exposed the seeded file under such a process environment. The final route explicitly uses an empty route-local service and no longer leaks that alternate configuration into its API contract.

## Remaining limitation

This closes repository-level T26 behavior only. The operator environment list/detail API is intentionally empty/non-authoritative; consumers needing recorded lifecycle truth must use the operator workflow/state source. Provider evidence and SQL rollout service configuration remain external to this packet.
