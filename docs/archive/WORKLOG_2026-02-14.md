## What I’m Changing First

1. `get_hours_by_goal`: replace full hierarchy hydration + Python traversal with SQL aggregation filtered by date range.
2. `get_leadership_metrics`: replace nested relationship loading with flatter, targeted queries and deterministic in-memory aggregation.
3. `get_krs_needing_checkin`: remove unnecessary eager-loaded `tasks` relationship and keep only fields required for stale check-in detection.
4. Deadline status correctness/perf: normalize deadline utility to support SQLModel objects + datetime values directly, eliminating exception-heavy call paths.
